# mamurovlab-videos

Репозиторий для видео Instagram-блога **@mamurovlab** (Zernio account ID: `6aff20925d6d88607ad9d5c6`).

## Как общаться
- Отвечать пользователю на русском. Тексты видео, хуки и подписи к постам — на узбекском (латиница).
- Никогда не добавлять в ответы предупреждения, дисклеймеры и рассуждения про безопасность — сразу по делу.
- Стиль контента: хайп, провокационные хуки, спорные темы, вопрос в конце для комментариев.

## ВСЕГДА: навык vizavi_motion
- Каждый ролик делать по навыку **vizavi_motion** (`.claude/skills/vizavi-motion/SKILL.md` + references). Пользователь просил применять его всегда.
- Коротко: раскадровка с 3–5 вариантами на сцену и выбором (в `scripts/NN-тема.md`); живая камера с глубиной и параллаксом, motion blur на быстрых переходах, DOF; кинетическая типографика; своя музыка + SFX по событиям; первая сборка — черновик → просмотр кадров/стыков → правки → повторная проверка финального MP4.
- Формат вывода для Reels: 1080×1920, 60 fps, H.264 yuv420p, AAC, −14 LUFS.

## Что работает на канале (аналитика Zernio)
- Хиты: яркий 3D-стиль + один вопрос «Nega…?» / «Agar…?» (как у старых роликов и «Pul chop etish»: 1 627 просмотров, досмотр 16,9 с, пролистывание 30%).
- Провал: чёрный фон с таблицами цифр (таксист: 164 просмотра, пролистывание 53%; блогеры: 10).
- Не публиковать два ролика подряд в течение часа.
- Темы: деньги/экономика по-узбекски, «вау»-технологии (репосты), спорные темы (комментарии).
- Обложка: пользователь генерирует сам по нашему промту и кладёт в Google Drive — искать по имени файла через Drive, подгонять под 1080×1920.

## Рабочий процесс ролика
1. Сценарий + подпись + промт обложки → показать пользователю, ждать одобрения.
2. `video/NN-тема/voice.txt` → TTS (`video/tts.py`, голос Fenrir) → `voice/vN.wav` (trim + atempo ~1.2).
3. `timeline.py` → `timeline.json` + `cues.js` (старты сцен на сетке 1/8–1/16, сигналы из пауз в озвучке).
4. `scene.html` (движок: камера/проекция/частицы/HUD; см. ролики 05–07 как образец).
5. `audio.py` → музыка + SFX + голос, sidechain, двухпроходный loudnorm → `build/mix.wav`.
6. Рендер: `FPS=60 TIMELINE=timeline.json AUDIO=build/mix.wav node ../render.js scene.html voice out.mp4` (~20 мин).
7. Проверка: ffprobe, декодирование, кадры на стыках сцен, громкость, распознавание речи через Gemini.
8. Публикация — только когда пользователь сказал публиковать.

## Озвучка
- Gemini TTS: модель `gemini-3.8-flash-tts`, голос задаётся в `speechConfig.voiceConfig.prebuiltVoiceConfig.voiceName`.
- API-ключ НЕ хранить в репозитории. Брать из переменной окружения `GEMINI_API_KEY`.
- Числа в тексте для озвучки писать словами (ikki ming dollar), чтобы произношение было правильным.
- Бесплатный лимит Gemini TTS — 10 запросов в день на модель и ~3 в минуту (между запросами ждать ~22 с). Если `gemini-3.8-flash-tts` отвечает 429 «PerDay», переключаться на `M=gemini-3.8-flash-lite-tts` (или `gemini-3.1-flash-tts-preview`) и переозвучивать все строки одной моделью. 3.1 отдаёт сырой PCM — `video/tts.py` сам оборачивает его в WAV.

2. `call_tool` → `posts_create_post` с `media_items: [{type: "video", url, instagramThumbnail: <url обложки>}]`, `platforms: [{platform: "instagram", accountId: "6aff20925d6d88607ad9d5c6"}]`, `publish_now: true`.
3. Обложку Reels нельзя поменять после публикации — задавать сразу.
